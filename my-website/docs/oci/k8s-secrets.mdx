# Plantillas `k8s` para secretos locales

Dónde: las plantillas y el script están en `MtdrSpring/backend/utils/k8s-secrets/`.

Propósito: permitir a un desarrollador nuevo crear, paso a paso, los secretos esperados por el deployment sin subir valores sensibles al repo.

Pasos rápidos (para un desarrollador nuevo):

1. Revisar los templates en `MtdrSpring/backend/utils/k8s-secrets/`.
2. Editar `create-local-secrets.sh` y reemplazar `REPLACE_ME_*` por valores de prueba locales.
3. (Opcional) Preparar un directorio `wallet/` con los ficheros del Oracle wallet (no subirlo al repo).
4. Ejecutar:

```bash
cd MtdrSpring/backend/utils/k8s-secrets
chmod +x create-local-secrets.sh
./create-local-secrets.sh
```

5. Verificar que los secretos están creados:

```bash
kubectl get secrets
kubectl describe secret dbuser
```

Notas importantes:
- Nunca pongas el wallet real en el repositorio. Usa `kubectl create secret generic db-wallet-secret --from-file=wallet/` y distribuye el wallet por canal seguro.
- Los archivos `*-template.yaml` son plantillas: si prefieres aplicar manifiestos en lugar de `kubectl create secret`, rellena los valores base64 en los campos `data`.
- Cuando prepares CI/CD, sustituye estos comandos por pasos que obtengan secretos desde OCI Vault o HashiCorp Vault.

Dónde documentarlo en el repo:
- `MtdrSpring/backend/utils/k8s-secrets/README.md` contiene el propósito y los enlaces rápidos.
- Esta página (`my-website/docs/oci/k8s-secrets.mdx`) es la referencia de onboarding para desarrolladores.
