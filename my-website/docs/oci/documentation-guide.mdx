# Documentación: Cómo Usarla

Este directorio documenta todo lo necesario para entender el proyecto, configurarlo y deployarlo.

## Archivos principales

### 1. **local-setup-architecture.mdx**
- **Qué es**: Explicación de la arquitectura y flujo de setup local
- **Para quién**: Todos (especialmente si es tu primer día)
- **Temas**: Dónde van los secretos, por qué el wallet no va en Docker, cómo funciona el flujo

### 2. **secrets-guide.mdx** ⭐ EMPEZAR AQUÍ
- **Qué es**: Guía paso a paso de de dónde sacar CADA secreto
- **Para quién**: Cualquiera configurando el backend por primera vez
- **Temas**: 
  - Qué es perfil, JWT, credenciales DB, wallet
  - De dónde descargarlo en OCI
  - Formatos esperados
  - Troubleshooting

### 3. **iac-guide.mdx**
- **Qué es**: Descripción de la infraestructura como código (Terraform)
- **Para quién**: DevOps, SRE, o si necesitas entender/cambiar OCI
- **Temas**: VPC, Database, LoadBalancer, registro de contenedores

### 4. **k8s-deployment.mdx**
- **Qué es**: Cómo deployar en Kubernetes (OKE en OCI)
- **Para quién**: Ops, deploy automation
- **Temas**: Manifests, secretos en K8s, LoadBalancer, health checks

### 5. **scripts-flow.mdx**
- **Qué es**: Documentación de los scripts (build, setup, deploy, undeploy)
- **Para quién**: Developers que quieren entender los scripts
- **Temas**: Qué hace cada script, cómo debuguear, extensiones

### 6. **hardcoding-risks.mdx**
- **Qué es**: Análisis de qué secretos estaban hardcodeados y por qué era un riesgo
- **Para quién**: Team leads, security reviews
- **Temas**: El Dockerfile viejo con hardcoding, cómo lo solucionamos

## Flujo típico: Primer setup

Si es tu primer vez configurando el backend:

1. Lee: **local-setup-architecture.mdx** (5 min)
   - Entiende dónde van las cosas

2. Lee: **secrets-guide.mdx** (10 min)
   - Entiende qué necesitas de OCI

3. Corre desde raíz del repo:
   ```bash
   ./scripts/setup.sh
   ```
   - Responde las preguntas siguiendo secrets-guide.mdx

4. Corre:
   ```bash
   ./scripts/build.sh
   ```

Listo. Backend compilado y listo para correr.

## Flujo típico: Deploy en OCI

Si necesitas deployar en Kubernetes en OCI:

1. Lee: **iac-guide.mdx** (si necesitas entender infraestructura)
2. Lee: **k8s-deployment.mdx** (como deployar)
3. Lee: **scripts-flow.mdx** (para entender deploy.sh y undeploy.sh)

## Si hay errores

- **Conexión a BD rechazada**: secrets-guide.mdx → Troubleshooting
- **JWT error**: secrets-guide.mdx → JWT_SECRET
- **Wallet corrupto**: secrets-guide.mdx → Oracle Wallet
- **Docker no corre**: scripts-flow.mdx → build.sh section
- **Deploy falla**: k8s-deployment.mdx → Troubleshooting

## Regla de oro

**Los secretos NO van en el código, NO van en Docker, NO se commitean.**

Todo va en:
- `.env.local` (gitignore-ado, local)
- K8s Secrets (producción)
- OCI Vaults (recomendado para prod)

## Resumen rápido

```
Tu computadora:
  ./scripts/setup.sh    → .env.local + wallet/
  ./scripts/build.sh    → imagen Docker
  docker run            → contenedor local

OCI:
  Terraform            → infraestructura
  K8s manifests        → deployment
  K8s Secrets          → secretos seguros
```

¿Necesitas algo específico? Usa el índice de la izquierda o busca en esta documentación.
