# Documentación: Cómo Usarla

Este directorio tiene TODO lo necesario. Aquí está cómo usarlo según tu situación.

## 🚀 Estoy haciendo Setup por PRIMERA VEZ

**Lee en este orden:**

1. **setup-checklist.mdx** (5 min)
   - Qué tienes listo, qué no
   - Paso a paso del setup

2. **jwt-secret-guide.mdx** (5 min)
   - Entiende qué es JWT_SECRET
   - Cómo generarlo
   - Por qué no se hardcodea

3. **secrets-guide.mdx** (referencia)
   - Detalles de cada secreto
   - Dónde encontrar cada cosa en OCI

**Luego corre:**
```bash

```

## 📝 Resumen rápido

```
Tu computadora:
  1. ./scripts/setup.sh    → Crea .env.local + copia wallet
  2. ./scripts/build.sh    → Maven compile + Docker build
  3. docker run            → Contenedor local

OCI:
  • Terraform             → VPC, Database, LoadBalancer
  • K8s manifests         → Deployment en OKE
  • K8s Secrets           → Secretos seguros en prod
```

## 🔒 Regla de oro

**Los secretos NO van en:**
- ❌ Código (.java, .properties en repo)
- ❌ Docker (ENV hardcodeado)
- ❌ Git (commit de .env.local)

**Los secretos VAN en:**
- ✅ `.env.local` (local, gitignore-ado)
- ✅ K8s Secrets (producción)
- ✅ OCI Vault (producción, recomendado)
