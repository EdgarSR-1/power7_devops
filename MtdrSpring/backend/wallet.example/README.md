# Wallet Files Required (Not Tracked in Git)

This directory is a template only.

For Oracle profile (`SPRING_PROFILES_ACTIVE=oracle`), copy the real wallet files provided by your team into:

- `MtdrSpring/backend/wallet/`

Expected files:

- `cwallet.sso`
- `ewallet.p12`
- `ewallet.pem`
- `keystore.jks`
- `truststore.jks`
- `ojdbc.properties`
- `sqlnet.ora`
- `tnsnames.ora`
- `README`

Do not commit `MtdrSpring/backend/wallet/`.
