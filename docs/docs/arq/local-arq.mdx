# Arquitectura de Backend

Actualmente el backend tiene 3 folders importantes:
- MtdrSpring: alli se construyo todo el backend en java y tiene comandos y configuraciones por limpiar de docker, pom, etc.
- docs: carpeta que contiene el sitio Docusaurus con la documentación del proyecto (antes llamada my-website). Aquí se documenta el backend y el proceso de deploy, tanto en local como en OCI.
- videos: videos tutoriales del profe.
