# Documentación: Estado actual y despliegue

Esta documentación explica cómo está configurado el repositorio ahora (Power7 / MtdrSpring), qué archivos y secretos se usan, y el flujo mínimo para construir y desplegar la imagen Docker en instancias OCI.

## Resumen rápido de la configuración

- El backend principal está en `MtdrSpring/backend`.
- Variables de runtime se guardan en `MtdrSpring/backend/.env.local` (gitignored). Use `./scripts/setup.sh` para generarlo localmente.
- Wallet de Oracle (si se usa Oracle ATP) debe colocarse en `MtdrSpring/backend/wallet` (carpeta gitignored) y entonces se monta en el contenedor en `/mtdrworkshop/creds`.

## Variables importantes que genera/espera `./scripts/setup.sh`

- `JWT_SECRET` (obligatorio): clave para firmar JWT, mínimo 32 caracteres.
- `SPRING_DATASOURCE_URL` (obligatorio si `SPRING_PROFILES_ACTIVE=oracle`): JDBC usando TNS alias (ej. `jdbc:oracle:thin:@reacttodok7toc_tp`). No incluir `?TNS_ADMIN` en la URL.
- `SPRING_DATASOURCE_USERNAME` / `SPRING_DATASOURCE_PASSWORD` (obligatorio si usas la DB).
- `TNS_ADMIN` (default `/mtdrworkshop/creds`): path dentro del contenedor donde se monta el wallet.
- `TELEGRAM_ENABLED`, `TELEGRAM_BOT_TOKEN` (opcional): para habilitar el bot Telegram de pruebas.
- `DEEPSEEK_API_KEY` (opcional): para características AI.

## Dónde obtener cada dato

- JWT_SECRET: generar localmente (`openssl rand -base64 32`).
- Wallet: descargar desde OCI Console en la cuenta que posee el Autonomous DB (Database → tu ATP → DB Connection → Download Wallet). Si el DB está en otra cuenta, pide al admin que te entregue el ZIP del wallet.
- DB credentials: te las debe proporcionar el owner del ATP.

## Flujo local de prueba (build + run)

1. Genera `.env.local` con el script interactivo:

```bash
cd /path/to/repo
./scripts/setup.sh
```

2. Coloca el wallet en `MtdrSpring/backend/wallet` (si te conectas al ATP):

```bash
unzip Wallet_<name>.zip -d /tmp/wallet
rm -rf MtdrSpring/backend/wallet/*
cp -R /tmp/wallet/* MtdrSpring/backend/wallet/
```

3. Construye y corre localmente (el script monta el wallet en runtime si el perfil es `oracle`):

```bash
RUN_LOCAL=1 ./scripts/build.sh
# o manualmente:
docker build -t agileimage:0.1 MtdrSpring/backend
docker run -p 8080:8080 --env-file MtdrSpring/backend/.env.local \
  -v $(pwd)/MtdrSpring/backend/wallet:/mtdrworkshop/creds:ro agileimage:0.1
```

4. Revisar logs:

```bash
docker logs $(docker ps -qf "ancestor=agileimage:0.1") --tail 200 -f
```

## Flujo de despliegue mínimo a instancias OCI

1. Subir imagen a un registry (OCIR): `docker tag` y `docker push` a `iad.ocir.io/<namespace>/repo:tag`. Necesitas un Auth Token (OCI Console → User → Auth Tokens).
2. Desde cada instancia que correrá el contenedor:
  - Asegura `docker` instalado y `docker login` a OCIR con el auth token.
  - Coloca `MtdrSpring/backend/.env.local` y la carpeta `wallet` en un path seguro (ej: `/home/opc/backend/`).
  - Ejecuta `docker pull` y `docker run` con `--env-file` y `-v /path/to/wallet:/mtdrworkshop/creds:ro`.

## Prevenciones y buenas prácticas

- Nunca commitees `.env.local` ni la carpeta `wallet` (están en `.gitignore`).
- Para producción, usa un secret manager (OCI Vault, K8s Secrets) y monta secretos en tiempo de despliegue.
- Si la base de datos está en otra cuenta OCI, solicita al admin del DB: el `wallet.zip`, `tnsnames.ora`/alias a usar y permitir acceso de red (allowlist de IPs o peering VCN).
