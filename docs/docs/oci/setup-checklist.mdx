## Si algo falla

**P: "No puedo encontrar la connection string"**
- Ve a OCI Console > Database > Tu ATP > Database Connection > Show Connection String

**P: ".env.local dice que falta algo"**
- Verifica que respondiste todas las preguntas en setup.sh
- Si falta algo, corre de nuevo: `rm MtdrSpring/backend/.env.local` y luego `./scripts/setup.sh`

**P: "¿Puedo commitear `.env.local`?"**
- **NO.** Está en `.gitignore` por seguridad.

**P: "¿Puedo cambiar el JWT_SECRET después?"**
- Sí, pero los tokens anteriores dejarán de ser válidos. Hazlo solo si vas a rotar el secreto de ese entorno.
