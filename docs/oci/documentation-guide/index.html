📝 Resumen rápido​

Tu computadora:
  1. ./scripts/setup.sh    → Crea .env.local + copia wallet
  2. ./scripts/build.sh    → Maven compile + Docker build
  3. docker run            → Contenedor local

OCI:
  • Terraform             → VPC, Database, LoadBalancer
  • K8s manifests         → Deployment en OKE
  • K8s Secrets           → Secretos seguros en prod

🔒 Regla de oro​

Los secretos NO van en:

  • ❌ Código (.java, .properties en repo)
  • ❌ Docker (ENV hardcodeado)
  • ❌ Git (commit de .env.local)

Los secretos VAN en:

  • ✅ .env.local (local, gitignore-ado)
  • ✅ K8s Secrets (producción)
  • ✅ OCI Vault (producción, recomendado)
